\# Changelog



All notable changes to this project will be documented here.



\## \[1.0.0] - 2026-11-14



\### Added

\- Health score calculation for every Power Automate flow (0-100 scale)

\- Color-coded dashboard with Healthy, At Risk, and Critical bands

\- Scoring deductions for inactive owner, never-run flows, high error rate, flow turned off, and inactivity

\- Filter by health status and flow status

\- Export full flow report to Excel

\- Last Successful Run column to distinguish flows that never ran from flows that ran but failed

\- xUnit test suite covering all scoring scenarios
